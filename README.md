# 🎵 Spotify Clone

A React-based music player application showcasing modern web development practices.

## Features

- Music playback and player controls
- Context API for state management
- Responsive UI with Tailwind CSS

## Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS
- **Routing**: React Router
- **State Management**: Context API
